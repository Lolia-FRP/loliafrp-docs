## 验证服务器运行状态

确定您已经在服务器中看见了形如这一行 `[11:45:14 INFO]: Done (0.001s)! For help, type "help"` 的日志。

这代表您的服务器已经正常启动并且玩家可以加入服务器。

## 获取服务器的本地端口

一般而言，在 `server.properties` 中，找到 `server-port=25565` 这一行即可确认，如果您修改了本地端口，那么以您修改后的为准，本教程默认为 25565。

## 创建隧道

在网页控制台上创建一个隧道，类型为 TCP，本地端口设置为刚才获取的本地端口 `25565`，然后创建隧道即可。

此处假设新建的隧道连接地址为 `cn-frp-1.qwq.fan:14514`

## 启动隧道

根据您使用的客户端，启动您刚才创建的隧道。

## 客户端如何加入

将网页控制台显示的远程地址直接**复制粘贴**到 Minecraft 的多人游戏 - 添加服务器的服务器地址

## 进阶配置

### PROXY protocol配置

对于服务器服主来说某些时候您可能需要分析玩家的ip地址，那么您就需要配置 PROXY protocol。

#### Paper

Paper `1.18.2+` 原生支持 `v2`。先关闭服务端自带的代理检测（默认关闭），再开启 PROXY protocol：

```properties
# server.properties
prevent-proxy-connections=false
```

```yaml
# config/paper-global.yml
proxies:
  proxy-protocol: true
```

#### 4.4 Velocity

```toml
# velocity.toml
prevent-client-proxy-connections = false

[advanced]
haproxy-protocol = true
```

#### 4.5 BungeeCord

```yaml
# config.yml
listeners:
- query_port: 25577
  proxy_protocol: true
```

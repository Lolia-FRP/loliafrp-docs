## 客户端配置

持续维护客户端教程非常麻烦，因此推荐直接前往 <https://manual.littlesk.in/yggdrasil/client> 查阅。如果您自建了 `blessing-skin`等，则后续的 `littleskin.cn` 替换为您自己的外部登录api端点即可。

### 联机 Mod

使用外置登录进行联机时，不需要安装皮肤修复类 Mod，也能正常加载皮肤。

## 服务端配置

:::caution
请务必启用 `online-mode`。Authlib-injector的原理是将源代码内写死的正版验证服务器地址替换为外置地址，它的正确意思是向远程服务器验证，所以启用外置登录后必须开启 `online-mode`。
:::

大多数的外置登录都通过 authlib-injector 实现，此处也以 authlib-injector 为例。

:::caution
请始终使用单一的身份验证服务器。同时使用多个身份验证服务器会导致许多意想不到的问题；尽管有一些项目例如`yggdrasil-official-proxy` 可以允许这么做，但并不完美，例如皮肤问题等。
:::

### 获取 JAR 文件

从 [authlib-injector 官方地址](https://authlib-injector.yushi.moe/) 下载最新版本的 JAR 文件，放入服务端启动脚本或服务端文件所在的目录中。下文示例使用 `authlib-injector-1.2.8.jar`，请替换为实际下载的版本。

### 单服务端

1. 将服务器配置文件 `server.properties` 中的 `online-mode` 设为 `true`

```properties
online-mode=true
```

2. 在服务端启动命令的 `-jar` 参数前添加：

```bash
-javaagent:authlib-injector-1.2.8.jar=littleskin.cn
```

完整的启动命令示例：

```bash
java -javaagent:authlib-injector-1.2.8.jar=littleskin.cn -jar server.jar
```

| 参数 | 说明 |
| --- | --- |
| `authlib-injector-1.2.8.jar` | authlib-injector 的 JAR 文件路径或文件名。 |
| `littleskin.cn` | LittleSkin 的 Yggdrasil API 地址简写，authlib-injector 会自动补全为 `https://littleskin.cn/api/yggdrasil`。如果需要使用HTTP明文协议，需要手动加协议头。 |

### Velocity & BungeeCord

Proxy 与每个子服务端都需要配置 authlib-injector，在各自的启动命令 `-jar` 参数前添加：

```bash
-javaagent:authlib-injector-1.2.8.jar=littleskin.cn
```

1. 检查 `config.yml` 或 `velocity.toml` 确保 `online-mode = true`

2. 检查每个子服务端的 `server.properties`，确保 `online-mode` 为 `false`：

```properties
online-mode=false
```

Velocity / Waterfall / BungeeCord 的完整启动命令示例：

```bash
java -Xms512M -Xmx512M -javaagent:authlib-injector-1.2.8.jar=littleskin.cn -jar proxy.jar
```

子服务器参考 [单服务端](#单服务端) 配置的示例，但**不要打开`online-mode`**。

## 准备 Apache

Windows 没有官方二进制，可以从 [Apache Lounge](https://www.apachelounge.com/download/) 下载；解压后把 `Apache24` 放到 `C:\Apache24`。默认配置中的 `SRVROOT` 指向这个目录，放到别处时要同步修改 `conf/httpd.conf` 开头的 `Define SRVROOT`。

Linux 直接用发行版的包：Debian / Ubuntu 是 `apache2`，RHEL 系是 `httpd`。

| 路径 | 说明 |
| --- | --- |
| `bin/httpd.exe`（Linux 为 `bin/httpd`） | 主程序 |
| `conf/httpd.conf` | 主配置文件 |
| `htdocs/` | 默认站点根目录 |
| `logs/` | `error.log` 与 `access.log` |
| `modules/` | 模块目录 |

## 启动并验证

Windows 下进入 `bin` 目录：

```bat
httpd -t
httpd -k start
```

`httpd -t` 校验配置，`-k start` 启动。浏览器访问 `http://127.0.0.1`，看到 `It works!` 即表示启动成功。默认监听 `80` 端口，站点根目录为 `htdocs`。

Linux 下（Debian / Ubuntu）：

```sh
sudo apache2ctl configtest
sudo systemctl start apache2
```

:::note
Windows 下 `httpd -k start` 会在当前控制台里运行，关掉窗口服务就停了。需要长期运行建议装成服务，见下方常用命令。
:::

## 放置站点文件

把网页文件放进 `htdocs/`，或修改 `DocumentRoot` 指向实际目录，`DocumentRoot` 与 `<Directory>` 要写成同一个路径：

```apache
DocumentRoot "C:/Apache24/htdocs"
<Directory "C:/Apache24/htdocs">
    Options Indexes FollowSymLinks
    AllowOverride None
    Require all granted
</Directory>
```

Windows 下路径使用正斜杠即可。Linux 下还要保证运行 Apache 的用户（通常是 `www-data` 或 `apache`）对该目录有读取权限。

## 反向代理

如果您的服务已经在本机其它端口上运行（例如 Java、Node.js、面板等），不需要把站点文件放进 `htdocs/`，让 Apache 把请求转发过去即可。先启用 `mod_proxy` 与 `mod_proxy_http`：

```apache
LoadModule proxy_module modules/mod_proxy.so
LoadModule proxy_http_module modules/mod_proxy_http.so
```

再添加转发规则：

```apache
ProxyPreserveHost On
ProxyPass        "/" "http://127.0.0.1:8080/"
ProxyPassReverse "/" "http://127.0.0.1:8080/"
```

`ProxyPass` 的路径和末尾的斜杠要与目标地址对应。需要按域名区分站点时写在 `VirtualHost` 里：

```apache
<VirtualHost *:80>
    ServerName example.com

    ProxyPreserveHost On
    ProxyPass        "/" "http://127.0.0.1:8080/"
    ProxyPassReverse "/" "http://127.0.0.1:8080/"
</VirtualHost>
```

若后端是 WebSocket 服务，还要加载 `mod_proxy_wstunnel`，并把 ws 路径单独转发：

```apache
LoadModule proxy_wstunnel_module modules/mod_proxy_wstunnel.so

ProxyPass        "/ws" "ws://127.0.0.1:8080/ws"
ProxyPassReverse "/ws" "ws://127.0.0.1:8080/ws"
```

`ProxyPass` 按书写顺序匹配，`/ws` 要写在 `/` 前面，否则会被 `/` 先接走。

Apache 转发时默认会附加 `X-Forwarded-For`、`X-Forwarded-Host`、`X-Forwarded-Server`（`ProxyAddHeaders` 默认开启），后端读取 `X-Forwarded-For` 即可拿到来源地址。

## 创建隧道

在面板的[隧道创建](/tutorials/dashboard/create-tunnel)页面选择 **HTTP** 隧道：

| 参数 | 填写内容 |
| --- | --- |
| 本地 IP | `127.0.0.1` |
| 本地端口 | Apache 实际监听的端口，默认 `80` |

若本机 `80` 端口已被占用，可以把 `Listen` 改成其它端口（如 `8080`），并把隧道的本地端口一并改掉。

## 绑定域名

在隧道详情中拿到形如 `cn-frp-1.qwq.fan` 的节点域名，为您的域名添加 CNAME 记录指向它，具体填写规则见 [DNS 配置](/tutorials/web/dns-config)。

## 获取访客真实 IP

经过 FRP 转发后，Apache 看到的来源地址是 frpc 的地址（通常是 `127.0.0.1`），访问日志、按 IP 限制之类依赖来源 IP 的功能都会失效。

需要启用 `mod_remoteip`（Debian / Ubuntu 可执行 `a2enmod remoteip`），配置 `RemoteIPHeader` 与 `RemoteIPInternalProxy`。具体写法见 [获取访客真实IP](/tutorials/web/get-realip)。

## HTTPS

需要 HTTPS 时，可以启用 AutoTLS 由客户端自动签发证书，也可以自行在 Apache 上配置证书。两种方式见 [AutoTLS](/tutorials/advanced/autotls)，证书本身的原理见 [TLS 与证书](/classroom/basics/tls)。

## 常用命令

| 操作 | 命令 |
| --- | --- |
| 校验配置是否正确 | `httpd -t` |
| 启动 | `httpd -k start` |
| 重启（改完配置） | `httpd -k restart` |
| 停止 | `httpd -k stop` |
| 安装为 Windows 服务 | `httpd -k install` |
| 卸载 Windows 服务 | `httpd -k uninstall` |

Windows 服务的默认名为 `Apache2.4`，安装时需要管理员权限，也可以用 `httpd -k install -n 自定义名称` 指定。Linux 下用 `systemctl restart apache2`（RHEL 系为 `httpd`）。

## 常见问题

### 改了配置但没有生效

执行 `httpd -k restart`。若命令报错，先用 `httpd -t` 查看是哪一行配置有问题。

### 启动失败且没有任何提示

Windows 下双击或通过快捷方式启动时，错误信息不会显示在窗口中。请在 `bin` 目录用命令行执行 `httpd -t`，或查看 `logs/error.log`。

### 反向代理返回 500 或 503

确认 `mod_proxy` 与 `mod_proxy_http` 已经加载；Linux 下用 `apache2ctl -M | grep proxy` 查看已加载的模块。

### 访问日志里记录的全是 127.0.0.1

这是 FRP 转发后的正常现象，需要配置 `mod_remoteip` 才能拿到访客真实 IP，见 [获取访客真实IP](/tutorials/web/get-realip#apache)。

### 80 端口被占用

Windows 下可执行 `netstat -ano | findstr :80` 查看占用进程；也可以把 `Listen` 改成其它端口，同时修改隧道的本地端口。

### 启动时提示没有设置 ServerName

提示形如 `AH00558: httpd: Could not reliably determine the server's fully qualified domain name`，不影响运行；在 `httpd.conf` 中设置 `ServerName` 即可消除。

## 准备文件

WinSW 是一个把普通程序包装成 Windows 服务的小工具，提供 .NET 版（`WinSW.NET462.exe`）和 x64 版，**两者的配置格式和命令完全相同**，本文以 .NET 版为例。.NET 版需要 .NET Framework 4.6.2 或更高版本，Windows 10/11 自带 4.8，可以直接使用。

从 [WinSW Releases](https://github.com/winsw/winsw/releases) 下载对应版本，与 `frpc.exe` 放在同一个目录，例如 `C:\loliafrp`：

```text
C:\loliafrp\
├── frpc.exe          Lolia CLI
├── loliafrp.exe      WinSW.NET462.exe 改名而来
└── loliafrp.xml      服务配置
```

WinSW 要求**配置文件与可执行文件同名**，所以把 `WinSW.NET462.exe` 重命名为 `loliafrp.exe`，再在同目录新建 `loliafrp.xml`。

:::note
winsw v2.13.0的构建脚本疑似写错了，如果文件名是 `WinSW-x64.exe_Debug` 或 `WinSW-x64.exe_Release`的话，把 `.exe_Release`改成 `.exe`，如果您没有看到扩展名，则可能是 Windows 文件资源管理器没有打开显示文件扩展名。
:::

## 编写服务配置

`loliafrp.xml`：

```xml
<service>
  <id>loliafrp</id>
  <name>LoliaFRP CLI</name>
  <description>Lolia CLI 隧道服务</description>

  <executable>%BASE%\frpc.exe</executable>
  <arguments>-t 隧道id:节点TOKEN</arguments>
  <workingdirectory>%BASE%</workingdirectory>

  <startmode>Automatic</startmode>
  <onfailure action="restart" delay="10 sec"/>
  <resetfailure>1 hour</resetfailure>

  <logpath>%BASE%\logs</logpath>
  <log mode="append"/>
</service>
```

| 配置项 | 说明 |
| --- | --- |
| `id` | 服务标识，安装后即服务名 |
| `executable` | 要启动的程序。`%BASE%` 表示 WinSW 可执行文件所在目录 |
| `arguments` | 传给 frpc 的参数 |
| `workingdirectory` | 进程工作目录，AutoTLS 的 `./.autotls-cache` 相对它解析 |
| `startmode` | `Automatic` 表示开机自启 |
| `onfailure` | 进程异常退出后 10 秒重新拉起 |
| `logpath` / `log` | frpc 的输出写入该目录，`append` 为追加模式 |

多个隧道写在同一条参数里：

```xml
<arguments>-t 隧道1:节点TOKEN1 -t 隧道2:节点TOKEN2</arguments>
```

使用配置文件启动时，把参数换成 `-c %BASE%\frpc.toml` 即可，配置中的相对路径同样以 `workingdirectory` 为基准。

## 安装并启动

以管理员身份打开 PowerShell，进入该目录：

```powershell
cd C:\loliafrp
.\loliafrp.exe install
.\loliafrp.exe start
```

检查状态：

```powershell
.\loliafrp.exe status
```

也可以使用 `Get-Service loliafrp` 查看。

## 常用操作

| 操作 | 命令 |
| --- | --- |
| 安装服务 | `.\loliafrp.exe install` |
| 启动服务 | `.\loliafrp.exe start` |
| 停止服务 | `.\loliafrp.exe stop` |
| 重启服务 | `.\loliafrp.exe restart` |
| 查看状态 | `.\loliafrp.exe status` |
| 卸载服务 | `.\loliafrp.exe uninstall` |

安装与卸载需要管理员权限，卸载前请先停止服务。

## 查看日志

frpc 的日志默认输出到 stdout，由 WinSW 写入 `logs` 目录：

| 文件 | 内容 |
| --- | --- |
| `loliafrp.out.log` | frpc 的 stdout |
| `loliafrp.err.log` | frpc 的 stderr |

## 更新客户端

```powershell
.\loliafrp.exe stop
```

替换 `frpc.exe` 后重新启动服务：

```powershell
.\loliafrp.exe start
```

`logs` 与 `.autotls-cache` 目录不要删除，后者被删除会触发重新申请证书。

## 注意事项

- 快捷启动的配置只在 frpc 启动时拉取一次，在面板修改隧道配置后需要重启服务才会生效。
- 同一条隧道只能有一个实例在线。注册服务后，不要再手动运行 `frpc -t ...` 启动同一条隧道。
- frpc 首次登录失败时会退出进程（`loginFailExit` 默认开启），由 `onfailure` 在 10 秒后重新拉起；token 失效时会持续重试，日志中可以看到具体错误。
- `<arguments>` 中的 token 会出现在 xml 和 frpc 进程的命令行中。可以把 xml 的权限限制为仅管理员可读，或改用 `-c` 配置文件启动并限制该文件的读取权限。

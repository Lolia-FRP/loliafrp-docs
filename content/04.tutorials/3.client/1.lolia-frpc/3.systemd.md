## 准备二进制

把 `frpc` 拷贝到 `/usr/local/bin` 并给予执行权限：

```bash
sudo cp frpc /usr/local/bin/frpc
sudo chmod 755 /usr/local/bin/frpc
frpc -v
```

```text
LoliaFRP-CLI 0.71.4
```

输出的版本应与发布页的 v 标签一致。

## 创建运行账户

frpc 只需要主动连接节点，不监听特权端口，因此不必以 root 运行。创建一个专用的系统账户，并准备一个工作目录：

```bash
sudo useradd --system --no-create-home --shell /usr/sbin/nologin loliafrp
sudo mkdir -p /var/lib/loliafrp
sudo chown loliafrp:loliafrp /var/lib/loliafrp
```

:::note
部分发行版（如 RHEL 系）的 `nologin` 位于 `/sbin/nologin`，如果上面的命令提示 shell 路径不存在，按实际路径替换即可。
:::

工作目录用于存放运行时产生的文件。启用 AutoTLS 时，面板下发的 `cacheDir` 是 `./.autotls-cache`，相对工作目录，因此该目录必须可写。

## 编写服务配置

新建 `/etc/systemd/system/loliafrp.service`：

```ini
[Unit]
Description=LoliaFRP CLI
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=loliafrp
Group=loliafrp
WorkingDirectory=/var/lib/loliafrp
ExecStart=/usr/local/bin/frpc -t 隧道id:节点TOKEN
Restart=on-failure
RestartSec=10s

[Install]
WantedBy=multi-user.target
```

把 `ExecStart` 中的 `隧道id:节点TOKEN` 换成面板「连接配置」里复制的值。多个隧道可以写在同一条命令里，frpc 会在一个进程中并行运行：

```ini
ExecStart=/usr/local/bin/frpc -t 隧道1:节点TOKEN1 -t 隧道2:节点TOKEN2
```

:::caution
frpc 首次登录失败时会退出进程（`loginFailExit` 默认开启），登录成功后与节点断开则会自行重连、不会退出。因此 `Restart=on-failure` 负责拉起启动失败的情况，`RestartSec=10s` 避免 token 失效等问题导致的高频重启。
:::

如果使用配置文件启动，把 `-t ...` 换成 `-c /var/lib/loliafrp/frpc.toml` 即可，配置中的相对路径（例如 `cacheDir`）同样以 `WorkingDirectory` 为基准。

## 启用服务

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now loliafrp
```

`enable` 会注册开机自启，`--now` 会立即启动。检查运行状态：

```bash
systemctl status loliafrp
```

## 查看日志

frpc 的日志输出到 stdout，由 systemd 收集到 journal：

```bash
journalctl -u loliafrp -f
```

日志时间使用 RFC3339 格式，`<...>` 中是输出该行的源码位置。按 `q` 退出 `journalctl`。

## 常用操作

| 操作 | 命令 |
| --- | --- |
| 查看状态 | `systemctl status loliafrp` |
| 跟踪日志 | `journalctl -u loliafrp -f` |
| 重启 | `systemctl restart loliafrp` |
| 停止 | `systemctl stop loliafrp` |
| 禁用开机自启 | `systemctl disable --now loliafrp` |

## 更新客户端

替换二进制后重启服务：

```bash
sudo cp frpc /usr/local/bin/frpc
sudo chmod 755 /usr/local/bin/frpc
sudo systemctl restart loliafrp
```

`.autotls-cache` 目录不要删除，否则会重新申请证书并可能触发 Let's Encrypt 的签发频率限制。

## 注意事项

- 快捷启动的配置只在 frpc 启动时拉取一次，在面板修改隧道配置后需要 `systemctl restart loliafrp` 才会生效。
- 同一条隧道只能有一个实例在线。注册 systemd 服务后，不要再手动执行 `frpc -t ...` 启动同一条隧道。
- `ExecStart` 中的 token 会出现在 unit 文件、`systemctl cat` 和进程列表中。介意的话把 unit 文件权限设为 `600`，或改用 `-c` 配置文件启动并限制配置文件的读取权限。
- frpc 收到 SIGTERM 后会优雅断开连接（约 0.5 秒），systemd 默认的停止流程即可，不需要额外配置 `KillSignal`。

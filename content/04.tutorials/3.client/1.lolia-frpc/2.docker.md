如果您更习惯使用容器化部署，我们也提供了官方 Docker 镜像。

## 拉取镜像

```shell
docker pull ghcr.io/lolia-frp/loliacli-frpc:latest
```

::callout{icon="i-heroicons-arrow-down-tray" color="blue"}
**国内用户**：如遇拉取缓慢，可使用镜像加速：

```shell
docker pull ghcr.milu.moe/lolia-frp/loliacli-frpc:latest
```

::

镜像有两个：

| 镜像 | 说明 |
| --- | --- |
| `ghcr.io/lolia-frp/loliacli-frpc` | 仅含 frpc，入口为 `/usr/bin/frpc`。 |
| `ghcr.io/lolia-frp/loliacli-frps` | 仅含 frps，供自建节点使用。 |

`latest` 随默认分支构建，另外提供形如 `0.71.4`、`0.71` 的版本标签，生产环境建议固定到具体版本。镜像支持 `amd64`、`arm64`、`arm/v7` 三种架构，Docker 会自动选择。

## 快速启动

**使用快捷启动参数：**

```shell
docker run -d --name loliafrp \
  --network=host \
  --restart=unless-stopped \
  ghcr.io/lolia-frp/loliacli-frpc:latest \
  -t 隧道id:节点TOKEN
```

## 持久化证书（AutoTLS 用户）

如果启用了 AutoTLS 功能，请务必挂载证书缓存目录：

```shell
docker run -d --name loliafrp \
  --network=host \
  --restart=unless-stopped \
  -v /path/to/autotls-cache:/.autotls-cache \
  ghcr.io/lolia-frp/loliacli-frpc:latest \
  -t 隧道id:节点TOKEN
```

::callout{icon="i-heroicons-light-bulb" color="blue"}
**提示**：将 `/path/to/autotls-cache` 替换为您本地的持久化目录路径，确保容器重建后证书不会丢失。
::

镜像的工作目录为 `/`，配置中的相对路径以它为基准，因此证书缓存位于容器内的 `/.autotls-cache`。

## Docker Compose

创建 `docker-compose.yml` 文件：

```yaml
services:
  loliafrp:
    image: ghcr.io/lolia-frp/loliacli-frpc:latest
    container_name: loliafrp
    network_mode: host
    restart: unless-stopped
    command: -t 隧道id:节点TOKEN
```

**启用 AutoTLS 时的配置：**

```yaml
services:
  loliafrp:
    image: ghcr.io/lolia-frp/loliacli-frpc:latest
    container_name: loliafrp
    network_mode: host
    restart: unless-stopped
    command: -t 隧道id:节点TOKEN
    volumes:
      - ./autotls-cache:/.autotls-cache
```

启动服务：

```shell
docker compose up -d
```

日志通过 `docker compose logs -f` 或 `docker logs -f loliafrp` 查看。

## 查看版本

```shell
docker run --rm ghcr.io/lolia-frp/loliacli-frpc:latest -v
```

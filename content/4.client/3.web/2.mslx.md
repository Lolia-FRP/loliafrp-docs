# MSLX Lolia FRP 插件

本插件基于 [Lolia FRP 开放 API](https://docs.lolia.link/developers/openapi) 制作，可以让您在 [MSLX](https://mslx.mslmc.cn) 中快速添加您的 Lolia FRP 隧道，无需进行繁琐的额外配置。

## 相关项目链接

# 插件安装与配置

## 部署 MSLX

您需要一个 MSLX 才可以使用本插件：[https://mslx.mslmc.cn](https://mslx.mslmc.cn) 。

## 安装插件

直接在 MSLX 的插件中心即可一键安装和启用 Lolia FRP 插件。

![安装MSLX插件](/client/web/1.install-mslx-plugin.png)

## 使用插件

前往 MSLX 的 「隧道列表」- 「创建隧道」- 「Lolia FRP」选项卡。

授权登录您的 Lolia FRP 账户即可在 MSLX 中管理和导入您的 FRP 隧道。

> 由于 OAuth 2.0 的回调特性需要回调地址，授权将经过 「MSLX 文档站」相关页面中转授权码。MSLX 文档站点不会存储您的任何授权码或 Token 信息（相关源码可见 MSLX 文档项目 Github ）。

## 写在前面

这一页文档是面向初次使用的用户，尽可能使用详细的步骤和图文解释，如果您认为您的计算机操作和阅读理解水平足够跳过本页，则无需阅读。

:::tip
开始之前：还没有 Lolia FRP 账号的话，请先前往 [dash.lolia.link](https://dash.lolia.link) 注册。建议先把 `frpc` 加入杀毒软件白名单，否则可能安装成功却无法启动，详见[常见问题](/faq)。
:::

## 下载 LoliaShizuku

首先确定您已经下载了 LoliaShizuku，如果您还没有下载，请先阅读[简介](/client/gui/loliashizuku/loliashizuku)获取如何安装LoliaShizuku的指导。

## 快速入门

安装过程相当简单，我们总是推荐使用 installer，不再附图因为只需要点点点即可，如果您的英文阅读能力受限，点击`Next >`和`Install`即可。

安装完成后，双击桌面上的 LoliaShizuku 快捷方式或开始菜单的 LoliaShizuku，您应该看到如下的界面。

![安装完成](/client/gui/shizuku_installed.png)

## 登录 Lolia FRP 账号

点击`使用 LOLIA FRP 账号登录`，浏览器会自动打开授权页面。

![授权确认](/client/gui/shizuku_auth.png)

在页面右下角点击`授权`，即可自动回到客户端并进入主页。

![主页面](/client/gui/shizuku_main_page.png)

:::tip
浏览器没有自动弹出？切换到浏览器即可，它可能只是被其他窗口挡住了。请勿点击`拒绝`。
:::

## 安装 frpc 核心

LoliaShizuku 本身不包含 frpc 核心，首次使用需要先安装，否则隧道无法启动。

### 进入 frpc 管理

点击`设置`，再点击`frpc 管理`。

![frpc 管理](/client/gui/shizuku_settings_frpc_install.png)

### 选择下载源（可选，国内网络推荐）

由于某些众所周知的原因，您并不总是与GitHub连接良好。

如果您访问 GitHub 缓慢或下载失败，可以先更换下载源，再点击安装。

![打开下载源下拉框](/client/gui/shizuku_select_mirrors_step1.png)

第一个下拉框选择`内置镜像`，第二个下拉框任选一个镜像源。

![选择镜像源](/client/gui/shizuku_select_mirrors_step2.png)

| 镜像源 | 说明 |
| --- | --- |
| `gh.milu.moe` | Milu GitHub 镜像 |
| `cdn.akaere.online` | Akaere GitHub 路径镜像 |
| `hub.xiaomocs.com` | XiaoMo GitHub 路径镜像 |
| `mirrors.locyan.cn` | 乐青云镜像 |

记得点击`保存设置`。

![保存下载源](/client/gui/shizuku_select_mirrors_step3.png)

保存成功后会显示绿色提示框。

![保存成功](/client/gui/shizuku_settings_saved.png)

### 开始下载

点击`安装 FRPC`，等待进度条走完。

![正在下载 frpc](/client/gui/shizuku_frpc_downloading.png)

### 下载失败

更换一个镜像源并点击`保存设置`，然后重新点击`安装 FRPC`。

![重试下载 frpc](/client/gui/shizuku_retry_download_frpc.png)

四个镜像源都尝试过后仍然失败，请参考[常见问题](/faq)排查杀毒软件误报与 SmartScreen 拦截。

## 下一步

安装好 frpc 核心之后，就可以在`隧道`页面启动隧道了。

如果您还没有创建隧道，请先阅读[隧道创建](/web-management/tunnel/create-tunnel)。

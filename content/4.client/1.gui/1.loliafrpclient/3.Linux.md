Linux 版界面与 Windows 版一致，只有下载与运行方式不同。
:::

## 下载 LoliaFrpClient

打开控制台的[软件下载](https://dash.lolia.link/dash/downloads)页，选择 `LoliaFrpClient`。

`操作系统`选 `linux`，`架构`选 `amd64`，点击`下载`。控制台提供 `.AppImage` 与 `.tar.gz` 两种，本文以 AppImage 为例。

![在控制台下载](/client/gui/loliafrpclient/Linux/download_it_in_browser.png)

## 添加执行权限

AppImage 下载后默认不能执行，需要先授权。两种方式任选一种。

**方式一：终端**

1. 在文件管理器里右键空白处 → `在终端打开`。

![在终端打开](/client/gui/loliafrpclient/Linux/right_click_to_enable_a_terminal_here.png)

2. 执行：

```shell
chmod +x LoliaFrpClient_*_linux-x64.AppImage
```

![chmod +x](/client/gui/loliafrpclient/Linux/chmod+x.png)

**方式二：文件属性**

右键 AppImage → `属性` → `权限` → 勾选`允许执行文件`。

![勾选允许执行文件](/client/gui/loliafrpclient/Linux/use_gnome_file_to_add_executable.png)

勾选后双击即可运行。

![已允许执行](/client/gui/loliafrpclient/Linux/afterclick_executable.png)

:::tip
双击没有反应？可以先尝试使用终端然后输入`./LoliaFrpClient_vx.x.x.x_linux-x64.AppImage`（注意此处是你下载的文件的实际版本，不要直接复制）。  
亦有可能是系统缺少 FUSE 支持，可以改用 `.tar.gz` 版本。
:::

## 登录 Lolia FRP 账号

1. 点击左下角`设置`，展开`账户`卡片，点击`登录`。
2. 点击客户端里显示的链接，会自动跳转到浏览器授权页。核对页面上显示的用户码与客户端一致，再点击`授权`。

![设备授权](/client/gui/loliafrpclient/oauth.png)

## 安装 frpc 核心

LoliaFrpClient 本身不包含 frpc 核心，首次使用需要先安装，否则隧道无法启动。

1. 点击左侧`Frpc 管理`，右上角会显示`核心版本 · 未安装`。

![Frpc 管理](/client/gui/loliafrpclient/Linux/example_tunnel_status.png)

2. 点击右上角`安装 / 更新`，等待提示`完成`。

![安装 frpc](/client/gui/loliafrpclient/Linux/install_frpc.png)

:::tip
下载缓慢或失败时，勾选`控制`卡片里的`下载走镜像加速`，再点一次`安装 / 更新`。
:::

## 启动隧道

1. 点击左侧`隧道`，可以看到已有的隧道，右上角可以`新建隧道`。

![隧道列表](/client/gui/loliafrpclient/Linux/open_a_tunnel.png)

2. 回到`Frpc 管理`，点击隧道右侧的`启动`；状态变为`运行中`后，下方`日志`会显示运行输出。

![启动隧道](/client/gui/loliafrpclient/Linux/tunnel_list_and_enable.png)

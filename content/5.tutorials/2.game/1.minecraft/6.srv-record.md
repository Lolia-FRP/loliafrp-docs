---
title: SRV 解析
description: 我的世界 Java 版 (Minecraft Java) 配置 SRV 解析记录，连接时无需填写端口号
---

:::tip
设置 SRV 解析只是为了让好友添加服务器时不用填端口号，**并非必须**。
只有 Minecraft Java 版支持 SRV 记录，基岩版不支持。
配置 SRV 记录后无法用 `ping` 测试连通性，在游戏内能连上即可。
:::

## 准备

- 一个托管在 Cloudflare 的域名（本教程以 Cloudflare 为例）
- 一条已启动的隧道，并从启动日志或隧道详情页拿到访问地址（如 `cn-frp-1.qwq.fan:11451`），冒号前是**节点域名**，冒号后是**远程端口**

隧道创建见 [Java 版局域网联机](/tutorials/game/minecraft/mcjavalan)。

## 添加 SRV 记录

打开 [Cloudflare 控制台](https://dash.cloudflare.com/)，在 Domains 列表中点击你想要设置 SRV 解析的域名

![选择域名](/tutorials/game/mcjava/mc-cloudflare-domain-selection.png)

在左侧菜单点击 `DNS`

![点击DNS](/tutorials/game/mcjava/mc-cloudflare-find-dns-settings.png)

点击 `记录`

![点击记录](/tutorials/game/mcjava/mc-cloudflare-click-record.png)

点击 `添加记录`

![点击添加记录](/tutorials/game/mcjava/mc-cloudflare-click-add-record.png)

按下表填写，然后点击 `保存`

![填写SRV记录](/tutorials/game/mcjava/mc-cloudflare-srv-set-record.png)

| 字段 | 填写内容 | 说明 |
| --- | --- | --- |
| 类型 | `SRV` | |
| 名称 | `_minecraft._tcp.mc` | 只有 `.mc` 部分可以自定义，`_minecraft._tcp` 不可修改 |
| 优先级 | `0` | |
| 权重 | `5` | |
| 端口 | 隧道的远程端口 | 例：`14514` |
| 目标 | 节点域名 | 例：`cn-frp-1.qwq.fan` |
| TTL | 自动 | |

保存后等待解析生效，具体时间由 TTL 决定，一般几分钟到 10 分钟。

## 在游戏中连接

假设你的域名是 `example.com`：

- 名称填 `_minecraft._tcp.mc`，在游戏中添加服务器时填 `mc.example.com` 即可连接
- 名称填 `_minecraft._tcp`（去掉 `.mc`），在游戏中添加服务器时直接填 `example.com`

均无需填写端口号。

## 一、准备服务端

1. 从 [Minecraft 官方网站](https://www.minecraft.net/zh-hans/download/server/bedrock) 下载 BDS。此处的教程使用 Windows 版本，Linux 版本差异不大。
2. 解压形如 `bedrock-server-1.26.61.1.zip` 的压缩包。

## 二、修改 server.properties

```properties
server-port=19132
online-mode=true
```

- `server-port`：服务器的本地端口，下面两条隧道都要填写这个数值，如果您修改了，请记得在下方替换掉信令隧道的本地端口部分。
- `online-mode=true`：保留账号验证，您和朋友使用自己的 Microsoft/Xbox 账号登录游戏

:::tip
默认情况下`allow-list=true`，即白名单处于打开状态，如果不希望打开白名单可以改为false；在控制台命令使用 `allowlist add 朋友的名字` 添加白名单
:::

保存后重新启动服务器，先在本机或局域网加入一次，确认能正常进入世界。

## 三、创建两条隧道

NetherNet 把一次连接拆成两步，所以需要一条 `TCP` 隧道和一条 `UDP` 隧道：

| 步骤 | 作用 | 协议 |
| --- | --- | --- |
| 信令 | 客户端先问「这个服务器要怎么连」 | `TCP`，HTTP(S) |
| 游戏 | 按信令给出的地址建立连接 | `UDP`，WebRTC |

两者端口号不需要相同：客户端只填写信令的地址，游戏地址由信令下发。

### 3.1 信令隧道

创建一个TCP隧道。

| 字段 | 填写 |
| --- | --- |
| 隧道类型 | `TCP` |
| 本地 IP | `127.0.0.1` |
| 本地端口 | `19132` |
| 远程端口 | 留空自动生成 |

此处我们假设新建的 TCP 隧道的连接地址为 `cn-frp-1.qwq.fan:14514`

如果点击了 `一键创建 TCP + UDP 同端口隧道`，那么跳过下面的游戏隧道创建过程。

### 3.2 游戏隧道

创建一个UDP隧道。

| 字段 | 填写 |
| --- | --- |
| 隧道类型 | `UDP` |
| 本地 IP | `127.0.0.1` |
| 本地端口 | `19132` |
| 远程端口 | 留空自动生成 |

此处我们假设新建的 UDP 隧道的连接地址为 `cn-frp-1.qwq.fan:14514`

记下 UDP 隧道的远程端口，下一步要写进服务端配置。

## 四、填写公网地址

需要获取 UDP 隧道对应的服务器的 IP 地址。

:::tip
对于 Windows, 可使用`nslookup -q=A cn-frp-1.qwq.fan`获取 IP 地址，Linux 使用`dig cn-frp-1.qwq.fan` 或者用网页 DNS 查询，总之任何方式能拿到 IP 地址都可以。
:::

打开 `server.properties`，把 UDP 隧道的公网地址写进去：

```properties
server-udp-ports=远程地址:远程端口:本地端口
```

填写格式形如 `server-udp-ports=191.98.10.1:14514:19132`

保存后重新启动服务器。

## 六、加入服务器

1. 打开 Minecraft 基岩版，在「服务器」页面点击「添加服务器」
2. 服务器名称自行填写，服务器地址填 `191.98.10.1`，端口填 `14514`。
3. 点击「添加并开始」加入

:::tip
TCP隧道必须先获取对应的IP地址，然后再填写加入服务器。
:::

## 七、常见问题

### 服务器能显示，但进不去，报错Terracotta

先检查 UDP 隧道是否开启，再核对 `server-udp-ports` 里的远程地址、远程端口与本地端口是否都填对。服务器能显示信息，不代表游戏连接已经正常。

### 域名和证书都正确，仍无法连接

确认玩家填写的是**信令隧道**的域名与端口，隧道日志里已经加载证书，并且两条隧道都处于启动状态。

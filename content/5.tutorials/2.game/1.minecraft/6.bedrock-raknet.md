---
title: 旧版基岩版（RakNet）
description: 旧版 BDS 的 RakNet 传输配置，一条 UDP 隧道即可多人联机
---

:::caution
本教程针对使用 RakNet 传输的旧版基岩版服务端，示例配置来自 `1.21.70.04`。新版服务端已改用 NetherNet，本教程对其不适用。
:::

由于 Bedrock Edition 的更新比较频繁且版本兼容性非常差，您应当很快就不再使用本教程。

故此处仅做简略的介绍，跟随本教程创建隧道并修改对应参数然后启动即可。

RakNet 只需要一条 UDP 隧道，所有玩家共用这一个端口。

## 一、创建隧道

| 字段 | 填写 |
| --- | --- |
| 隧道类型 | `UDP` |
| 本地 IP | `127.0.0.1` |
| 本地端口 | 先填 `19132`，等下需要改 |
| 远程端口 | 留空自动生成 |

创建完成之后找到形如 `cn-frp-1.qwq.fan:14514` 的连接地址，其中冒号的前半部分是域名，后半部分是端口。

然后在隧道的配置界面设置本地端口为远程端口，如 `14514`。

## 二、修改服务端配置

打开 `server.properties`，把监听端口改成同一个远程端口：

```properties
server-port=14514
```

改完后重启服务端，再启动隧道。

:::tip
RakNet 的服务器列表信息里带着服务端自己的端口，`server-port` 与远程端口不一致时 MOTD 显示不出来。这也是上面要把本地端口和 `server-port` 都改成远程端口的原因。
:::

:::warning
必须将 `enable-lan-visibility` 设为 `false`，否则服务端会直接忽略端口配置。
:::

## 三、让玩家加入

打开基岩版，在 `服务器` 页面点击 `添加服务器`，地址填 `cn-frp-1.qwq.fan`，端口填远程端口（例如 `14514`）。

## 四、常见问题

### 服务器列表里看不到 MOTD

`server-port` 或隧道本地端口与远程端口不一致，或者 UDP 隧道没有启动。

### 服务器能显示但进不去

核对隧道的本地端口、`server-port` 与远程端口三者是否一致，以及服务端是否已经启动完成。

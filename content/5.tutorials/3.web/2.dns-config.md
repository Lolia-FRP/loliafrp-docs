## HTTP(S) 应用

1. 准备自己的一个已备案域名，形如 `example.com`。

2. 在 Lolia 面板选择 `http` / `https` 隧道并创建（域名需先在[域名白名单](/web-management/domain-management/whitelist)中添加并验证通过）。

3. 在隧道配置中拿到形如 `cn-frp-1.qwq.fan:80`（`cn-frp-1.qwq.fan:443`）的“节点域名:端口”连接地址，然后复制节点域名部分。

4. 在您的域名的 DNS 处设置 CNAME 到节点域名，例如添加一个 CNAME 到 `cn-frp-1.qwq.fan` 并保存，等待解析生效。

5. 然后浏览器打开 `example.com`（替换为您自己的域名）。

### 填写规则

请前往您的域名 DNS 服务商处，在对应的根域名下添加一条 **CNAME 记录**：

| 字段 | 应填写的内容 |
| --- | --- |
| 记录类型 / 类型 | `CNAME` |
| 主机记录 / 记录名称 / 名称 | 根域名填 `@`，子域名填去掉根域名后的前缀（如 `www`） |
| 记录值 / 内容 / 目标 | 复制的节点域名，例如 `cn-frp-1.qwq.fan` |
| TTL | 保持默认即可（一般为 10 分钟或「自动」） |

:::caution
- 记录类型必须是 CNAME，不要误添加为 A、TXT 等其他类型
- 记录值只填节点域名，不要带 `:80`、`:443` 这类端口，也不要带 `http://`、`https://`
- 同一主机记录下如果已经存在 A 记录或 CNAME 记录，需要先删除原有记录，否则会冲突
:::

### 验证解析是否生效

在电脑上打开命令行（Windows 为 PowerShell 或命令提示符），将域名替换为您自己的域名后执行：

```bash
nslookup example.com 8.8.8.8
```

也可以使用在线 DNS 查询工具查看解析结果，例如 [Google Public DNS](https://dns.google/)、[DNSChecker](https://dnschecker.org/)。

返回结果中出现节点域名，即表示解析已经生效。

:::tip
星露谷物语的联机是**跨平台**的：可以让电脑开服，手机加入。本教程以 PC 版为例，移动版的注意事项请参考文末的**移动版说明**一节。
:::

:::note
建议使用电脑开服（作为游戏主）。手机的后台策略与网络环境可能影响开服的稳定性，用手机加入则没有这个问题。
:::

## 一、创建联机房间

启动游戏，点击主菜单中的 `合作` 按钮。

![主菜单合作按钮](/tutorials/game/stardewvalley/main_page.png)

在左上角选择 `主持`，然后选择已有的存档，或点击 `主持新农场……` 创建一个新存档。

![选择主持的存档](/tutorials/game/stardewvalley/select_a_save_to_open_multi.png)

进入游戏后，确认聊天框出现 `你现在是多人游戏的游戏主。` 的提示，此时联机房间已经创建完成。**联机期间请保持游戏运行。**

![游戏主提示](/tutorials/game/stardewvalley/host_server_enabled.png)

:::note
如果这里看不到您的本地存档，说明该存档还没有联机小屋，请参考后文的**建造联机小屋**一节，将本地存档转换为可联机的存档。
:::

## 二、创建隧道

### 2.1 选择隧道类型

访问：https://dash.lolia.link/dash/tunnel/add

选择 **UDP 隧道**，并选择想要使用的节点。

![选择UDP隧道](/tutorials/game/stardewvalley/create_tunnel_and_select_udp.png)

:::note
UDP 低延迟，适合游戏与语音，但某些节点不支持 UDP；如果无法选择，请更换节点或改用 TCP。
:::

### 2.2 填写隧道配置

- **本地 IP**：`127.0.0.1`
- **本地端口**：`24642`（星露谷物语的默认联机端口）
- **隧道名称**：（自定义，例如 `Stardew_Valley`）
- **远程端口**：`留空`（由系统自动分配）

![填写隧道参数](/tutorials/game/stardewvalley/fill_ip_and_port_in_dashboard.png)

填写完成后点击**创建**，页面会自动跳转到隧道详情页，并提示**隧道创建成功**。

![隧道创建成功](/tutorials/game/stardewvalley/created_tunnel.png)

## 三、启动隧道

### 3.1 打开客户端

本教程使用 **LoliaShizuku** 客户端。如果您还没有安装，请先阅读 [LoliaShizuku 快速入门](/client/gui/loliashizuku/usage)。

:::info
下载地址：https://github.com/Mxmilu666/LoliaShizuku/releases
:::

### 3.2 启动隧道

点击菜单栏 `隧道`，找到刚才创建的隧道（例如 `Stardew_Valley`），点击 `启动`。

![在客户端启动隧道](/tutorials/game/stardewvalley/turn_on_tunnel_in_loliashizuku.png)

启动后客户端会进入 **LoliaCLI Runner** 页面，在这里可以查看运行状态、隧道状态与 `frpc 运行日志`。

![启动后的运行页面](/tutorials/game/stardewvalley/after_running.png)

### 3.3 获取连接地址

隧道卡片上的 **目标** 地址（也可以在隧道详情页的**远程地址**中查看）就是好友需要填写的连接地址。

:::caution
星露谷物语原版没有密码保护功能，任何拿到地址的人都可以尝试加入。建议在不联机时关闭隧道，避免农场被陌生人进入。
:::

## 四、加入联机房间

1. 确认房主的游戏仍在运行、且客户端中的隧道处于启动状态
2. 好友打开星露谷物语，点击主菜单中的 `合作`，切换到 `加入` 标签页

   ![切换到加入标签页](/tutorials/game/stardewvalley/join_step1.png)

3. 点击上方的输入框，在弹出的 `输入 IP……` 窗口中填写房主提供的连接地址，然后点击 `OK`

   ![填写连接地址](/tutorials/game/stardewvalley/fill_ip_port_in_stardew_valley.png)

4. 连接成功后进入角色创建/选择界面，左下角的在线玩家列表中可以看到自己和房主

   ![加入成功](/tutorials/game/stardewvalley/finished_join.png)

:::note
如果无法加入，请确认：
- 房主的游戏仍在运行，且聊天框的「游戏主」提示没有消失
- 客户端中的隧道处于启动状态，`frpc 运行日志` 没有报错
- 地址填写完整，包含端口号，且没有多余的空格
- 隧道使用的节点支持 UDP 隧道
:::

## 五、建造联机小屋

其他玩家加入时都需要一间联机小屋，**每加入一名玩家就需要一间小屋**；本地存档也需要先建造小屋，才能用于联机。

联机小屋的建造属于游戏本身的玩法，详细图文步骤请参考 SakuraFrp 文档的[建造联机小屋](https://doc.natfrp.com/game/stardew-valley.html#build-cabin)（前往木匠的商店与罗宾对话，建造 `联机小屋`，建成后回家睡觉存档即可）。

## 六、移动版说明

手机版星露谷物语在 1.6 版本之后支持多人联机：

- **手机加入游戏**：按照上文「加入联机房间」的步骤操作即可，连接地址和电脑版完全相同
- **手机开服（作为游戏主）**：部分版本的多人在主界面默认是隐藏的，需要在英文界面用秘籍解锁，完整图文步骤请参考 SakuraFrp 文档的[移动版游戏开启联机](https://doc.natfrp.com/game/stardew-valley.html#mobile-multiplayer)

:::caution
不推荐使用手机开服：手机的后台策略与网络环境可能导致联机不稳定。更稳妥的做法是**用电脑开服、手机加入**。
:::

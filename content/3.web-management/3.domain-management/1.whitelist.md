---
title: 域名白名单
description: 在域名白名单页面添加并验证您的域名，验证通过后即可在创建 HTTP 隧道时选择该域名。
---

:::tip
只有添加到白名单并通过 DNS 验证的域名，才能在创建 HTTP 隧道时被选择；在中国大陆节点上创建 HTTP 隧道，还要求域名已完成备案。
:::

## 一、打开域名白名单页面

登录[面板](https://dash.lolia.link)，从左侧菜单进入**域名白名单**。

您会看见下图中的界面。

![域名白名单页](/dashboard/add_domain_whitelist.png)

## 二、添加域名

:::tip
- 不要包含协议部分与路径，例如 `http://`、`https://` 以及结尾的 `/`
- 必须是您自己持有、并且能够修改 DNS 解析记录的域名，因为后续需要为其添加验证记录
:::

在输入框中填写您的域名，确认无误后点击**添加域名**。

:::tip
未备案域名不能创建国内隧道。
:::

![输入域名](/dashboard/input_beian_domain.png)

提交成功后，右下角会提示**域名添加成功**，该域名会出现在**已添加域名**列表中，状态为**待验证**。

![域名添加成功等待验证](/dashboard/added_domain_waiting_for_verify.png)

:::caution
验证记录是为该域名专属生成的，请在验证完成前不要删除该域名。删除后重新添加会生成新的验证记录，需要重新配置 DNS。
:::

## 三、配置 DNS 验证记录

展开**已添加域名**列表中状态为**待验证**的域名，可以看到**验证步骤（DNS TXT）**，其中包含**记录名称**与**记录值**两项内容，两项内容右侧都提供了复制按钮，我们总是推荐您使用复制功能。

### 3.1 填写规则

请前往您的域名 DNS 服务商处，在对应的根域名下添加一条 **TXT 记录**：

| 字段 | 应填写的内容 |
| --- | --- |
| 记录类型 / 类型 | `TXT` |
| 主机记录 / 记录名称 / 名称 | 面板显示的记录名称，多数服务商只需填写去掉根域名后的前缀（如 `lolia_sjhmve7j`），部分服务商需要填写完整记录名称 |
| 记录值 / 内容 / 文本内容 | 面板显示的记录值，需要完整填写 |
| TTL | 保持默认即可（一般为 10 分钟或「自动」） |

:::caution
- 记录类型必须是 TXT，不要误添加为 A、CNAME 等其他类型
- 记录值必须完整准确，不要添加多余的空格、引号或换行
- 同一条记录名称下如果已经存在其他 TXT 记录，请保留原有记录并新增一条，不要直接覆盖
:::

判断记录名称是否填写正确的方法：保存时编辑窗口上方的提示通常会显示这条记录的完整名称（例如 Cloudflare 会显示「`lolia_sjhmve7j.example.com` 具有内容为 ... 的记录」），确认它与面板显示的记录名称一致即可。

### 3.2 以 Cloudflare 为例

登录 Cloudflare，进入您域名的 **DNS 记录** 页面，点击**添加记录**，在**类型**下拉框中选择 `TXT`。

![选择 TXT 类型](/dashboard/cloudflare_add_txt_step1.png)

- **名称**：填写记录名称的前缀部分，例如 `lolia_sjhmve7j`（Cloudflare 会自动补全您的根域名）
- **内容**：粘贴面板中复制的记录值
- 其余选项保持默认，点击**保存**

![填写记录名称与内容](/dashboard/cloudflare_add_txt_step2.png)

保存后，编辑窗口上方会显示这条记录对应的完整名称，请确认它与面板显示的记录名称一致。

## 四、完成验证

DNS 记录保存后不会立即全网生效，通常需要几分钟，部分服务商可能需要更久，请稍作等待后再点击刷新。

![返回面板点击刷新](/dashboard/return_to_dashboard_to_verify_added_dns_record.png)

- 点击刷新按钮后，如果 DNS 记录已经生效，右下角会提示**验证成功**，域名状态变为**已生效**
- 如果仍然显示**待验证**，请稍等几分钟后再次点击刷新；长时间无法通过，请参考下一节的排查方法

![验证成功](/dashboard/successfully_added_whitelist.png)

## 五、域名状态说明

| 状态 | 含义 |
| --- | --- |
| 待验证 | 域名已提交，但尚未通过 DNS TXT 验证，此时还不能在创建隧道时选择该域名 |
| 已生效 | 域名已通过 DNS 验证，可以在创建 HTTP 隧道时选择该域名 |

### 5.1 备案标记

域名验证通过后，域名后方会显示该域名是否已备案的标记：

- **已备案**：域名已在工信部登记备案，可以在**中国大陆节点**上创建 HTTP 隧道，面板会同时展示对应的 ICP 备案号
- **未备案**：只能在**境外节点**上创建 HTTP 隧道

![已备案域名](/dashboard/added_beian_domain_finished.png)

:::note
部分节点要求特定接入商的备案（例如阿里云的节点需要阿里云的接入备案），此处仅表示该域名已在工信部登记备案。
:::

## 六、常见问题

### 点击刷新后一直显示「待验证」
- DNS 解析通常需要几分钟到几十分钟才能全网生效，请稍作等待后再次点击刷新
- 确认 TXT 记录被添加在**正确的根域名**下，且记录名称没有多写或少写根域名部分（各 DNS 服务商对记录名称的填写要求不同，详见上一节的填写规则）
- 确认记录值完整无误，注意不要包含多余的空格、引号或换行；建议使用面板提供的复制按钮重新复制，避免手工输入出错

### 如何确认 TXT 记录是否已经生效

在电脑上打开命令行（Windows 为 PowerShell 或命令提示符），将记录名称替换为面板中显示的值后执行：

```bash
nslookup -type=TXT lolia_xxxxxxxx.example.com 8.8.8.8
```

也可以使用在线 DNS 查询工具查看解析结果，例如 [Google Public DNS](https://dns.google/)、[DNSChecker](https://dnschecker.org/)。

返回结果中出现面板显示的记录值，即表示解析已经生效，此时回到面板点击刷新即可通过验证。

### 更换 DNS 服务商或删除域名后重新添加
- 更换 DNS 服务商后，需要在新服务商处重新添加该 TXT 记录
- 删除域名后重新添加会生成新的验证记录，需要按新的记录名称与记录值重新配置 DNS

### 域名使用了 CDN / 代理会影响验证吗
不会。TXT 记录不受代理影响（例如 Cloudflare 的橙色云朵），无需关闭代理。

### 如何删除已添加的域名

在**已添加域名**列表中点击该域名后方的删除按钮即可。删除后该域名会从白名单中移除，如果此前已经用它创建了 HTTP 隧道，请及时处理这些隧道。

## 下一步

域名验证通过并显示**已生效**后，就可以在[隧道创建](/web-management/tunnel/create-tunnel)页面选择 **HTTP 隧道**并使用该域名了。

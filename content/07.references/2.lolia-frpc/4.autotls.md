title: AutoTLS
description: AutoTLS 的插件参数、启用条件与限制。
---

AutoTLS 在 https 隧道上由客户端本地通过 ACME 协议（TLS-ALPN-01）申请并续期证书，不需要手动提供证书文件。

## 配置

AutoTLS 是插件配置，写在 `[proxies.plugin.autoTLS]` 下。面板开启 AutoTLS 后，隧道「连接配置」中的 Lolia-CLI 专用配置 会包含以下内容：

```toml
[[proxies]]
name = "web"
type = "https"
customDomains = ["example.com"]
httpRedirect = true

[proxies.plugin]
type = "https2http"
localAddr = "127.0.0.1:80"

[proxies.plugin.autoTLS]
enable = true
email = 'usermail@yourmail.com'
cacheDir = './.autotls-cache'
caDirURL = 'https://acme-v02.api.letsencrypt.org/directory'
```

上述 `httpRedirect` 与 AutoTLS 相互独立，默认关闭，需要在面板上手动开启；开启后 frps 会把该域名的 HTTP 请求重定向到 HTTPS。不开启时只有 HTTPS 可访问。

## 参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| enable | bool | 是否启用。默认为 `false`。 |
| email | string | ACME 账户联系邮箱。默认为空。 |
| cacheDir | string | 证书与账户的缓存目录。启用时必填，相对路径以进程工作目录为基准。 |
| hostAllowList | []string | 允许申请证书的域名。默认为空，此时使用 customDomains。 |
| caDirURL | string | ACME 目录地址。默认为 Let's Encrypt 正式环境，可改为测试环境目录。 |

## 启用条件

- 隧道类型为 https。面板开启 AutoTLS 时同时启用 https2http 插件，把本地 HTTP 服务反向代理为 HTTPS 服务。
- 启用时 `crtPath` 与 `keyPath` 必须为空。
- 域名已解析到节点，且节点的 443 端口能回到客户端完成验证。
- cacheDir 所在目录可写。

## 现象

启动约 1 秒后客户端在后台预申请证书，日志形如：

```text
2026-11-17T09:27:51+08:00 INFO <plugin/autotls.go:119> LoliaFRP-CLI: [autoTLS][web] 域名 [example.com] 证书已就绪，过期时间 2027-02-15T08:00:00Z
```

续期由 ACME 客户端自动完成，不需要重启 frpc。证书只保存在 cacheDir 中，目录被删除后需要重新申请。

## 限制

| 限制 | 说明 |
| --- | --- |
| 通配符域名 | `*.example.com` 不会被申请，配置后被忽略并打印告警。 |
| 端口 | 依赖 443 端口完成验证，链路阻断 443 时无法签发。 |
| 频率 | Let's Encrypt 对同一域名有签发频率限制，频繁重建容器可能触发临时封禁。 |
| 多域名 | customDomains 中的每个域名分别申请。 |

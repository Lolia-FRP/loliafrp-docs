## 启动方式

frpc 有两种启动方式：由面板下发配置的快捷启动，和使用本地配置文件的常规启动。

| 方式 | 命令 | 配置来源 |
| --- | --- | --- |
| 快捷启动 | `frpc -t <id>:<token>` | 启动时从服务端拉取 |
| 配置文件 | `frpc -c <file>` | 本地 ini、yaml、json、toml 文件 |

同时指定 `-t` 与 `-c` 时只使用 `-t`，`-c` 指定的配置文件不会被读取。

## 快捷启动

```text
frpc -t <id[,id2,...]>:<token> [-t ...]
```

`-t` 可重复出现，也可在同一段内用逗号续写。

| 写法 | 示例 | 说明 |
| --- | --- | --- |
| 单个隧道 | `-t 10000:abcdef` | 隧道 10000 使用 token abcdef。 |
| 同一 token 多个隧道 | `-t 10000,10001:abcdef` | 只启动一个服务实例，同时承载这两个隧道。 |
| 多个 `-t` | `-t 10000:abcdef -t 10085:ghijkl` | 两个 token 各启动一个服务实例。 |
| 逗号续写 | `-t 10000:abcdef,10085,10086:ghijkl` | 10000 使用 abcdef，10085 与 10086 使用 ghijkl。 |

位于两个 `id:token` 之间、自身不带 token 的 id 归属后一个 token。

```shell
./frpc -t 10000:abcdefghijklmnop

./frpc -t 10000:abcdefghijklmnop -t 10085:qrstuvwxyz123456
```

启动行为：

| 行为 | 说明 |
| --- | --- |
| 同一 token 多个 id | 合并为一个服务实例。 |
| 不同 token | 并行启动多个服务实例，共用一个进程，日志以 `[i/N]` 前缀区分。 |
| 配置刷新 | 只在启动时拉取一次，在面板修改隧道配置后需要重启 frpc。 |
| 单实例失败 | 只打印错误，不影响其他实例。 |

token 会出现在进程命令行、shell 历史与 `docker inspect` 的输出中，不要分享完整命令。token 泄露后请在面板重建隧道。

## 配置文件

```shell
./frpc -c ./frpc.toml
```

`-c` 默认为 `./frpc.ini`，支持 ini、yaml、json、toml 四种格式。ini 已弃用，启动时会打印告警。配置格式与原版 frp 一致，面板「连接配置」中提供的原版 FRPC TOML 配置可直接使用。

`-c` 可重复或用逗号分隔，每个文件启动一个服务实例：

```shell
./frpc -c ssh.toml -c web.toml
./frpc -c ssh.toml,web.toml
```

通过 `--config_dir` 指定目录时，目录（含子目录）下的每个文件都会作为配置文件启动一个实例：

```shell
./frpc --config_dir ./conf
```

`--config_dir` 不筛选后缀，目录中不要放置配置文件以外的文件。

## 多隧道

| 场景 | 命令 | 服务实例数 |
| --- | --- | --- |
| 同一 token 多个 id | `-t 10000,10001:<token>` | 1 |
| 多个 token | `-t 10000:<token1> -t 10085:<token2>` | 2 |
| 多个配置文件 | `-c a.toml -c b.toml` | 2 |
| 配置目录 | `--config_dir ./conf` | 目录内文件数 |

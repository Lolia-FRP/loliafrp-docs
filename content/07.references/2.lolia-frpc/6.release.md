## 下载

发布包位于 [GitHub Releases](https://github.com/Lolia-FRP/lolia-frp/releases)，也可以在[网页控制台](https://dash.lolia.link/dash/downloads)下载。每个平台提供 zip（Windows）或 tar.gz 压缩包，以及校验文件 `sha256sum.txt`。

## 平台

| 系统 | 架构 |
| --- | --- |
| Linux | amd64、386、arm、arm64、loong64 |
| Windows | amd64、386、arm64 |
| macOS | amd64、arm64 |
| FreeBSD | amd64、386、arm64 |
| OpenBSD | amd64、386、arm64 |
| Android | arm（armv7）、arm64 |

除 Android 外为关闭 CGO 的静态构建，单文件即可运行。Android 版使用 CGO 单独构建。

## 构建

需要 Go 1.26.10 或更高版本（go.mod 中的 `go` 指令要求）。依赖通过 Go module 代理下载，国内网络可以先设置镜像：

```sh
go env -w GOPROXY=https://goproxy.cn,direct
```

使用仓库的 Makefile：

```sh
make frpc    # 只编译客户端，产物为 bin/frpc
make frps    # 只编译服务端，产物为 bin/frps
make         # 编译两端
make web     # 单独构建前端资源（需要 Node.js）
```

不使用 Makefile 时，可以直接执行等价命令：

```sh
GOOS=linux GOARCH=arm GOARM=7 CGO_ENABLED=0 \
  go build -trimpath -ldflags "-s -w" -tags "frpc,noweb" -o frpc ./cmd/frpc
```

### 构建标签

| 标签 | 说明 |
| --- | --- |
| `frpc` | 客户端构建，排除服务端专用代码。 |
| `frps` | 服务端构建，排除客户端专用代码。 |
| `noweb` | 跳过内置 Web 面板。仓库未构建前端资源（`web/frpc/dist`、`web/frps/dist` 不存在）时不加会报 `pattern dist: no matching files found`。 |

`make frpc`、`make frps` 不需要手动指定 `noweb`：Makefile 会检测这两个 dist 目录，缺失时自动追加。只有直接调用 `go build`、又没有先执行 `make web` 构建前端时，才要写成 `-tags "frpc,noweb"`。

### 交叉编译

| 变量 | 说明 |
| --- | --- |
| `GOOS` | 目标系统：`linux`、`windows`、`darwin`、`freebsd`、`openbsd`、`android`。 |
| `GOARCH` | 目标架构：`amd64`、`386`、`arm`、`arm64`、`loong64`、`mips`、`mipsle`、`mips64`。 |
| `GOARM` | 仅 `GOARCH=arm` 时有效，可取 `5`、`6`、`7`，默认为 `7`。 |
| `GOMIPS`、`GOMIPS64` | 仅 mips 系列有效，可取 `hardfloat`（默认）或 `softfloat`。 |
| `CGO_ENABLED` | 保持 `0`，产物为静态二进制。Android 版例外，需要 CGO 与 NDK。 |

以 Go 1.27.4、`-s -w` 加 `noweb` 构建为例，产物大小：

| 目标 | 大小 |
| --- | --- |
| `linux/arm`（GOARM=7） | 16.0 MB |
| `linux/arm64` | 15.7 MB |
| `linux/mips`、`linux/mipsle`（softfloat） | 18.1 MB |
| `linux/mips64` | 18.4 MB |

## 发布

推送 `v*` 标签后，CI 按上面的矩阵交叉编译，Windows 打包为 zip、其余平台打包为 tar.gz，生成 `sha256sum.txt` 并创建 Release。Android 使用 NDK 单独构建。

发布包的构建参数为 `CGO_ENABLED=0`、`-trimpath`、`-ldflags "-s -w -checklinkname=0"`、`-tags frpc` 或 `frps`；CI 未设置 `GOARM`，因此 arm 包使用默认的 `GOARM=7`。

## 发布包内容

| 文件 | 说明 |
| --- | --- |
| frpc(.exe) | 客户端。 |
| frps(.exe) | 服务端，自建节点时使用。 |
| LICENSE | 许可证。 |
| conf/frpc.toml | 上游示例配置，连接本地 127.0.0.1:7000，仅供格式参考。 |
| conf/frps.toml | 上游示例服务端配置。 |

conf/frpc.toml 是上游示例文件，不能直接用于连接 LoliaFRP。实际使用请从面板复制快捷启动命令或原版 FRPC 配置。

## 版本

```shell
./frpc -v
```

```text
LoliaFRP-CLI 0.71.4
```

版本号写在 `pkg/util/version/version.go` 的 `var version` 中，构建参数不会覆盖它，发版时需要修改该文件。

## 校验

```shell
sha256sum -c sha256sum.txt
```

```powershell
Get-FileHash .\发布包.zip -Algorithm SHA256
```

将输出的哈希与 sha256sum.txt 中对应行对比。

## 上游版本

Lolia CLI fork 自 [fatedier/frp](https://github.com/fatedier/frp)，持续跟随上游更新，并添加了快捷启动、AutoTLS、多隧道等能力。其余配置项参见 [conf/frpc_full_example.toml](https://github.com/Lolia-FRP/lolia-frp/blob/dev/conf/frpc_full_example.toml)。

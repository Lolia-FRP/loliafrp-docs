## 日志

默认输出到 stdout，格式为时间、级别、源码位置、固定前缀和消息：

```text
2026-11-17T09:27:49+08:00 INFO <sub/root.go:249> LoliaFRP-CLI: 已获取到配置文件 隧道名称="MC 联机" 使用节点="阿里云杭州-1"
2026-11-17T09:27:50+08:00 INFO <client/control.go:207> LoliaFRP-CLI: [1145141919810] [1.abcdefghijklmnop] 您可通过 cn-frp-1.qwq.fan:11451 访问您的服务
```

时间为 RFC3339 格式，级别为 trace、debug、info、warn、error。`<...>` 中是输出该行日志的源码位置，会随版本变化，反馈问题时请提供完整日志。

日志相关配置：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| log.to | string | 输出目标，`console` 或文件路径。默认为 `console`。 |
| log.level | string | 日志级别。默认为 `info`，无法识别的值会退回 `info`。 |
| log.maxDays | int | 日志文件保留天数。默认为 `3`，小于等于 `0` 时不清理。 |
| log.disablePrintColor | bool | 关闭终端颜色。默认为 `false`。 |

log.to 设为文件路径时按天轮转：跨天把当前文件重命名为 `<文件名>.YYYY-MM-DD`，并删除超过 log.maxDays 的文件。

多实例运行时日志交错输出，可用 `[i/N]` 前缀与 `启动 frpc 服务 [<文件>]` 区分实例：

```text
2026-11-17T09:27:49+08:00 INFO <sub/root.go:474> LoliaFRP-CLI: [1/2] 启动 token: abc***xyz (IDs: [10000 10001])
```

## 退出码

| 退出码 | 说明 |
| --- | --- |
| 0 | 正常结束（包括 Ctrl+C）、`-v`、`--help`，以及多实例模式下所有实例结束。 |
| 1 | 启动阶段错误：`-t` 格式错误、拉取配置失败、配置文件解析或校验失败、子命令执行失败。 |

多实例模式下单个实例失败只打印错误，进程最终仍以 0 退出。与节点的连接断开后会自动重连，进程不会因此退出。

## 报错信息

| 信息 | 说明 |
| --- | --- |
| `invalid token format '...', expected 'id[,id2,...]:token'` | `-t` 缺少冒号，或 token 为空。 |
| `invalid token format '...', id list is empty` | 冒号前没有隧道 id。 |
| `API returned status code: <code>` | 服务端拒绝请求，token 失效或隧道已删除。 |
| `API error: <消息>` | 服务端返回的业务错误。 |
| `failed to fetch config from API` | 网络不通、DNS 解析失败或被拦截。 |
| `failed to parse config` | 配置字段不合法或缺少必填项。 |
| `failed to render template` | 配置中的模板变量无法解析。 |
| `web server port should be set if you want to use this feature` | 使用了 status、reload、stop，但配置没有 webServer。 |
| `invalid autoTLS options: autoTLS.cacheDir is required when autoTLS.enable is true` | 启用 AutoTLS 但没有填写 cacheDir。 |

## 停止

Ctrl+C（SIGINT）或 SIGTERM 触发优雅关闭，约 0.5 秒内断开与节点的连接。多实例模式下每个实例各自响应，进程在所有实例退出后结束。
